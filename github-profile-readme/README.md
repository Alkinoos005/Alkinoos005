<h3><code>alkinoos@github:~$ cat about.txt</code></h3>

Full-Stack Developer and Electrical & Computer Engineering student based in Greece,
currently studying at the University of Western Macedonia. Splits time between
software (Python, Java, JavaScript/React) and hardware (Arduino, ESP32, 3D-printed
enclosures) — the kind of person who'd rather build the physical thing *and* the
app that talks to it. Actively exploring applied AI/ML, robotics (ROS), and ethical
hacking/cyber security on the side.

Currently juggling a handful of personal builds at once: a locally-running AI
assistant (`jarvis`), a discipline app with real stakes (`lock-in`), a habit-building
morning routine app (`arise`), a WALL-E-inspired robot, and a homegrown smart-home
setup — all while keeping `AlkinoosTech` as the main hub where things get versioned
and cleaned up. Self-described passionate perfectionist: focused, always something
on the bench, still compiling.
